# ala — AI 학습 분석실 인스턴스 환경 관리

SSH에서 Rocky Linux 10 x86_64 서버의 환경 설정과 Chrome 화면을 관리하는 도구입니다.
GNOME/GDM과 기존 sudo 사용자가 필요합니다.

공개 배포용 코드 기준선입니다. 설치 안내와 공개 릴리스는 준비 중입니다.
실제 장비의 설치·GPU·화면·재부팅 수용은 아직 완료하지 않았습니다.
