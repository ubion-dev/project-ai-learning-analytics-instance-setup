# 첫 설치와 운영 인계의 완료 기준

Labels: wayfinder:map
Status: resolved

## Destination

Rocky에서 SSH로 환경과 화면을 설정하고, 재접속·재부팅·업데이트·복구를 확인한 뒤 팀 개발자에게 설치 절차를 넘길 수 있는 첫 배포의 범위와 통과 기준을 결정한다.

## Notes

- 사용자가 프로젝트의 완성 범위를 정하기 위해 Wayfinder를 선택했다. Q1·Q2 추천안 수락으로 첫 수용 단위와 업데이트 범위를 확정했다. 이 지도의 설계 결정은 완료됐고 실행은 실제 장비 수용으로 이어진다.
- 로컬 Markdown 트래커를 사용한다. 티켓은 이 디렉터리의 issues에 두며 결정 질문과 답변을 기록한다.
- 결정 인터뷰에는 프로젝트의 grilling과 domain-modeling 스킬을 적용한다. 기존 합의는 [용어집](../../GLOSSARY.md), [설치 설계](../../docs/plans/ala-install-operations-plan.md), [첫 구현 계획](../../docs/plans/ala-first-implementation-plan.md)을 참조한다.
- RC40의 구현·배포 결과는 [진행 기록](../../docs/plans/ala-v1-progress.md)에 있다. 실제 장비 수용은 [수용 기록의 첫 설치 기준](../../docs/ACCEPTANCE.md)에 따라 진행한다. 필수 실패 항목은 수정 후 재검증하며 팀 개발자의 절차 재현을 인계 조건으로 둔다.
- 실제 장비·계정·주소·인증정보와 기관별 운영 결과는 공개 문서에 기록하지 않는다.
- 장비 역할과 물리 출력의 실제 연결은 현장 구성을 따른다. 비디오월의 패널 수와 OS 논리 출력 수는 구분한다.

## Decisions so far

- [첫 배포의 업데이트 운영 범위](issues/02-initial-update-operation.md) — 대표 PC의 버전 갱신·설정 보존·실패 결과 조회·기존 버전 복구 통과.

## Not yet specified

첫 설치 수용의 실행 경로가 정해졌다. 장비 확보·승인 범위 확인 후 수용 기록의 필수 항목을 실행하고, 실패 항목의 수정과 재검증을 이어간다.

## Out of scope

- 이번 지도는 첫 설치와 운영 인계의 경계를 정한다. 분석 입력부터 결과 표시까지의 제품 전체 수용, 회사 공통 관리 서비스와 기관 간 대규모 자동 업데이트, 공통 OS 이미지 제작은 별도 후속 범위로 둔다. 기존 장기 요구는 상위 설치 설계에서 계속 추적한다.
- 기관 전체의 장비별 설정 전달·일괄 배포·작업 결과 조회는 첫 대표 설치를 수용한 뒤 후속 목표로 구체화한다.
