# 대표 설치의 완료 판정

Type: grilling
Status: resolved
Parent: ../map.md
Blocked by: none

## Question

첫 배포를 인계 가능한 상태로 판단할 대표 설치의 단위와 통과 조건은 무엇인가?

추천안은 강의실 한 곳을 대표하는 DID 연결 PC 두 대와 논리 출력 네 개를 기준으로 삼는 것이다. 각 출력에 지정 사이트 또는 설정 안내가 표시되고, 화면 배치·해상도·화면 배율이 적용되며, SSH 재접속·재부팅 후 복원과 잘못된 배치의 확인 시간 초과 복원을 통과한다.

첫 실기기 점검은 확보된 한 대부터 시작할 수 있다. 위 대표 설치 전체의 결과가 모이면 첫 배포의 수용을 판정한다. 실제 장비 접근과 변경은 사용자가 지정한 장비와 승인 범위에서 진행한다.

## Comments

현 시점에서 이 기준은 제안이며 실기기 통과로 기록하지 않았다.

## Answer

사용자가 Q1에 추천안을 선택했다. 강의실 한 곳을 대표하는 PC 두 대·논리 출력 네 개를 첫 배포의 수용 단위로 정한다. 각 출력의 지정 사이트/설정 안내, 화면 배치·해상도·배율, SSH 재접속·재부팅 후 복원, 잘못된 배치의 30초 미확인 복원이 통과 조건이다.

확보된 한 대부터 시험하고 두 대 전체의 결과로 수용을 판정한다. 실기기 점검은 미수행이다. 필수 항목 실패는 해당 항목을 수정하고 재검증한 뒤 수용한다. 팀 개발자가 문서를 따라 설치·상태 조회·복구를 재현할 수 있는 절차를 인계한다.
