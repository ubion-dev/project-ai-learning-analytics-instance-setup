# 화면 관리의 배치도와 조작 개선

## 확정된 요구

- 사용자는 화면의 실제 좌표 관계와 해상도에 따른 상대 크기를 배치도에 반영하기를 요청했다.
- 화면 관리는 SSH 터미널에서 조작한다. 드래그 제거와 모니터별 지원 해상도·배율, 검토·적용·확인/복원 흐름은 기존 합의를 따른다.
- 첫 수용 단위는 기존 Wayfinder에서 확정한 대표 PC 두 대·논리 출력 네 개다.

## 이번 수정

- 논리 영역의 전체 경계에 단일 축척을 적용하고 터미널 셀의 가로·세로 비율을 보정한다. 세로 시작점의 작은 차이를 별도 줄로 확대하지 않는다.
- 도형 내부에서 내용을 다 표시할 수 없으면 모니터 정보 목록을 함께 제공한다. 작은 도형을 읽을 수 없거나 배치를 확인할 수 없으면 좌표 목록으로 표시한다.
- 사용자가 작은 십자 리모컨과 키보드 방향키, 기준 모니터의 상하좌우에 붙이기를 선택했다. 고정폭 버튼에 선택·기준 출력 번호를 표시하며 리모컨 포커스에서만 방향키를 처리한다.

## 확정된 조작 방식

- 작은 고정폭 십자 리모컨과 키보드 방향키를 함께 제공한다.
- 선택한 모니터를 기준 모니터의 상하좌우에 붙인다.

## 다음 CLI 개선의 검토 순서

대표 장비의 실제 설치 수용을 기준으로 사용 흐름을 검토한다. 화면 관리 진입에서 이상 대상과 다음 행동을 찾고, 해당 모니터를 선택해 설정을 편집하고, 검토·적용 뒤 실제 결과와 복원 여부를 확인하는 한 흐름을 먼저 평가한다.

화면 배치, 사이트 배정, 화면 코드 버전의 선택은 각각의 용어와 현재 적용 상태를 표시한다. 후속 기능은 이 흐름에서 막힌 지점과 대표 설치 수용 결과를 근거로 정한다.
