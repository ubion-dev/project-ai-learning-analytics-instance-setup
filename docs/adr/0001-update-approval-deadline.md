# 기관에 우선 승인 기회를 주고 기한 후 정책에 따라 업데이트한다

기관의 운영 일정과 장기 미갱신 문제를 함께 다루기 위해, 기관에 먼저 승인·유예 기회를 주고 사전 합의한 기한 이후 허용 점검 시간에 자동 적용하는 정책을 채택한다. CLI·프론트·애플리케이션과 OS·Chrome·GPU 드라이버·재부팅의 적용 조건은 구분하며, 기한 도래만으로 대상별 검사·승인 조건이나 긴급 중지를 해제하지 않는다. 구체적인 유예 기간·연장 범위·점검 시간·재부팅 허용 조건은 후속 설계에서 정하며, 이 결정은 실제 기관과의 정책 합의나 현재 장비에 대한 자동 작업 실행을 뜻하지 않는다.
