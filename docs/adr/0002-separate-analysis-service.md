# 분석 서비스와 장비 관리 도구의 개발 책임을 분리한다

마이크 음성 수신·STT·CCTV 분석 서버는 별도 분석 서비스 저장소에서 개발하고, 장비 관리 쪽은 해당 서비스의 설치·설정·실행·점검·갱신을 연결한다. 기존 ala 기능은 유지하며, 분석 알고리즘과 장비 설정을 하나의 구현·배포 단위로 합치지 않는다. ala를 유일한 관리 주체로 고정하지 않으며, 이후 교내 관리자 화면도 동일한 작업 실행 경로와 상태를 사용하도록 설계한다.

PC·서비스 운영과 카메라 제어의 네트워크 API는 별도 장비·분석 서버에서 제공하는 방향으로 좁힌다. 기존 ala가 수행하는 호스트 변경은 고정된 실행 경로를 재사용하며, ala 전용 관리 서버를 추가하거나 동일 작업을 두 구현에서 따로 실행하지 않는다. 구체적인 연동 계약은 [가이드 초안](../device-management-integration.md)에서 후속 확인한다.

분석 서비스는 컨테이너 이미지와 Compose 구성을 배포 단위로 사용한다. 장비별 설정·모델 파일·분석 결과·저장 데이터는 서비스 교체와 분리해 보존하고 삭제는 별도 명시 작업으로 취급한다. 실제 버전 호환·상태 확인·데이터 이전·복구 규약은 후속 설계에서 정하며, 고사양 PC에서 분석과 Chrome을 함께 실행하는 안은 성능 시험 후보로 유지한다.
