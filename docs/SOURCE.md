# 코드 구성과 배포 범위

ala는 Python CLI/TUI와 `scripts/rocky-linux/`의 Bash 설치 모듈로 구성됩니다.
공개 코드에는 학교별 구성·장비 목록·인증정보·내부 개발 이력을 포함하지 않습니다.
실제 구성과 실행 기록은 각 관리 대상 서버에 저장됩니다.

배포는 `scripts/build-release.py`가 허용한 파일과 해시가 고정된 의존성 wheel만 포함합니다.
소스 저장소 자체를 복사하거나 GitHub의 Source code 압축을 실행용 배포 파일로 사용하지 않습니다.
의존성의 저작권·라이선스 정보는 각 패키지에 포함된 메타데이터와 라이선스 파일을 따릅니다.
